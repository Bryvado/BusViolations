How to read this page

Histogram heights recalculate from the other active filters. The timeline retains the full date context while highlighted bars show the selected range; the fine distribution works the same way. Drag either handle or enter exact limits below.

Totals and non-map trends include every cleaned record. The map and hourly chart use records with valid D.C. coordinates. No chart or map uses a sample, and descriptive changes do not by themselves establish a cause.

Data: District of Columbia Geographic Information System. Interface and analysis code: BusViolations.
