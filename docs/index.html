How to read this page

The dashboard stores every cleaned record with a valid D.C. coordinate in compressed monthly Parquet files. The selected files are queried in your browser and rendered with WebGL; neither the heatmap nor the point layer uses a sample.

Summary totals also include cleaned records without usable coordinates, so the violations count can exceed the mapped-points count. Trend charts are descriptive and do not by themselves identify what caused a change.

Data: District of Columbia Geographic Information System. Interface and analysis code: BusViolations.
