# Data

The pipeline downloads records from the D.C. government's ArcGIS REST services. Data files are excluded from Git because the full extracts are large and can be reconstructed.

## Source inventory

| Dataset | Publisher | Coverage | Retrieval | Local output |
| --- | --- | --- | --- | --- |
| Moving violations | DCGIS | Monthly layers, 2024–2026 | Generated by `bus-violations download` | `raw/dc_moving_violations.parquet` |
| Parking violations | DCGIS | Monthly layers, 2024–2026 | Generated by `bus-violations download` | `raw/dc_parking_violations.parquet` |
| Combined violations | Derived | Available moving and parking layers | Generated by the downloader | `raw/dc_all_violations.parquet` |
| Clean analysis file | Derived | Valid downloaded records | Generated by `bus-violations clean` | `processed/dc_all_violations_clean.parquet` |

Service pattern:

```text
https://maps2.dcgis.dc.gov/dcgis/rest/services/DCGIS_DATA/Violations_{Moving|Parking}_{year}/MapServer
```

ArcGIS layer IDs 0–11 are treated as January–December. Months that do not yet exist are logged as unavailable. Other request failures stop the build so partial data cannot silently pass as complete.

## Folder roles

- `raw/`: untouched ArcGIS attributes plus source metadata.
- `interim/`: reserved for temporary joins or geocoding.
- `processed/`: cleaned analysis-ready data.

Do not manually edit a processed file. Change the code and rebuild it.
