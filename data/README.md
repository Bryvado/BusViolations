## Folder roles

- `raw/`: untouched downloads or exports.
- `interim/`: temporary cleaned, geocoded, or joined files.
- `processed/`: stable analysis-ready files produced by code.

Do not manually edit a file in `processed/`. Change the source code and rebuild it instead.
